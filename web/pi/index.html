PROVIEW SIGNAGE on Raspberry Pi

Turns a Raspberry Pi into a signage player that starts by itself when it is switched on.

You need

  • A Raspberry Pi 4 or 5 with Raspberry Pi OS (with desktop)
  • It connected to the internet and to the screen by HDMI

Install

On the Pi, open Terminal, paste this line and press Enter:

curl -fsSL https://app.proviewsignage.co.uk/pi/install.sh | bash

When it says Done, restart the Pi. The pairing code and QR appear on the screen: pair it from the Screens page of your dashboard.

Remove

curl -fsSL https://app.proviewsignage.co.uk/pi/install.sh | bash -s -- --remove
